TrmnlApi response: https://trmnl-plugins-prod.lucasp.net/api/v2/forecast

Field names are unit-agnostic. Actual units depend on the `units` query parameter:
    imperial (default): °F, mph, inches
    metric:             °C, km/h, mm

Query parameters:
    place       (v2) — city, postal code, or "latitude, longitude" pair (latitude first). Falls back to latitude/longitude when blank.
    latitude    (v1 required, v2 optional) — location latitude
    longitude   (v1 required, v2 optional) — location longitude
    units       — "imperial" (default) or "metric"
    hours       — number of hourly entries (1–25, default 25)
    days        — number of daily entries (1–14, default 6; Pirate Weather only supplies up to 7)
    provider    — "open-meteo" or "pirate-weather" (omitted by the plugin; server default applies)
    time_format — "12h" (default) or "24h" — controls the hourly "label" field
    fake        — "true" or "1" to inject randomized precipitation (testing; v1 only)

Template variables (injected at the top level, not nested under "data"):
    current.
        time                    (ISO 8601, e.g. "2026-02-28T14:00")
        temperature             (integer, °F or °C)
        apparent_temperature    (integer, "feels like", °F or °C)
        relative_humidity       (%, 0-100)
        precipitation           (inch or mm)
        condition               (string, e.g. "Clear", "Overcast", "Rain")
        icon_class              (CSS class, e.g. "wi-day-sunny", "wi-night-clear")
        wind_speed              (integer, mph or km/h)
        wind_direction_deg      (degrees, 0–360)
        wind_direction          (cardinal string, e.g. "N", "SW")
        is_day                  (boolean)
    hourly.
        entries                 (array of up to 25 objects, current hour + next 24h)
            time                (ISO 8601)
            label               (string, e.g. "2pm", "3pm"; "14:00", "15:00" when time_format=24h)
            temperature         (integer)
            precipitation_probability (%, 0–100)
            icon_class          (CSS class, day/night variant pre-computed)
            is_day              (boolean)
    daily.
        entries                 (array of up to "days" objects, today + next N-1 days; 14 max, 7 max from Pirate Weather)
            date                (date string, e.g. "2026-02-28")
            high                (integer, daily high temperature)
            low                 (integer, daily low temperature)
            condition           (string, e.g. "Clear", "Snow")
            icon_class          (CSS class, no day/night variant for daily)
            precipitation_probability (%, 0–100)
            sunrise             (ISO 8601, e.g. "2026-02-28T06:20")
            sunset              (ISO 8601, e.g. "2026-02-28T17:32")
    meta.
        cache                   (string: "fresh_fetch", "fresh_hit", or "stale_served")
        provider                (string: provider that actually served this response, e.g. "pirate-weather" or "open-meteo"; may differ from requested_provider on fallback)
        requested_provider      (string: provider the caller asked for)
        fetched_at              (ISO 8601 UTC timestamp of last upstream fetch)
        data_time               (ISO 8601, matches current.time)
        served_at               (ISO 8601 UTC timestamp when this response was served)
        age_seconds             (integer, seconds since fetched_at)
        time_format             (string: "12h" or "24h", echoes the requested format)
        upstream                (null when healthy; { status, error } when stale_served or when a fallback was used)
    place. (v2 only, present when the caller named a place)
        name                    (string, e.g. "Portland")
        admin1                  (string, e.g. "Maine"; display name, not ISO code)
        country                 (string, e.g. "United States")
        country_code            (ISO 3166-1 alpha-2, e.g. "US")
        latitude                (float)
        longitude               (float)
    error. (v2 only, present on failure instead of current/hourly/daily)
        code                    (stable string: place_missing, place_invalid, place_not_found, request_invalid, weather_unavailable)
        message                 (string, rendered on screen; quotes back the user's input)
        hint                    (string, shown where the layout has room)
